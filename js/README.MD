# Administrador de Sintéticas

Aplicación frontend construida con **HTML, CSS y JavaScript vanilla**, enfocada en buenas prácticas, código limpio y arquitectura escalable.

## ✨ Funcionalidades

- Agregar sintéticas
- Editar sintéticas
- Eliminar con confirmación
- Persistencia con LocalStorage
- Feedback visual al usuario
- Accesibilidad básica
- Micro-interacciones con CSS

## 🧠 Enfoque del proyecto

Este proyecto fue desarrollado con mentalidad profesional, aplicando:

- Separación de responsabilidades
- Código legible y mantenible
- Funciones pequeñas y claras
- Módulos ES6
- HTML semántico
- CSS organizado
- JavaScript sin frameworks
